# Machine Learning Foundations & Applications (NFO3016)

This repository hosts my coursework, practical labs, and algorithmic implementations for **NFO3016 Machine Learning** at Deakin University. It showcases foundational skills in feature engineering, model training, tuning, and deployment pipeline evaluations.

## 🧠 Core Competencies
* **Supervised Learning:** Building and evaluating robust classification and regression architectures (e.g., Decision Trees, Random Forests, Support Vector Machines).
* **Unsupervised Learning:** Discovering hidden patterns in unlabeled multi-dimensional data using clustering algorithms (K-Means, Hierarchical Clustering) and Dimensionality Reduction (PCA).
* **Model Optimization:** Fine-tuning hyperparameters using cross-validation and evaluating pipelines with precise metrics (Confusion Matrices, ROC-AUC, F1-Score).

## 🛠️ Tech Stack & Tooling
* **Language:** Python
* **Frameworks:** Scikit-Learn, SciPy
* **Data Engineering:** Pandas, NumPy
* **Visualization:** Matplotlib, Seaborn
